# CRUD

Путь к Core-файлу:

`Core/CRUD.php`

## Назначение

`CRUD` предоставляет базовые операции с одной таблицей MySQL: создание,
получение, обновление и удаление строк. Класс наследуется от `ConnectDB`,
поэтому настройки подключения берутся из `.env` проекта.

## Создание объекта

В конструктор передаётся имя таблицы:

```php
use Core\CRUD;

$users = new CRUD('users');
```

Имя таблицы должно состоять только из латинских букв, цифр и символа `_`,
причём первым символом должна быть буква или `_`. Недопустимое имя вызывает
`InvalidArgumentException`.

## Методы

### create

Добавляет одну строку. Колонки и значения передаются в одинаковом порядке.

```php
$users->create(
    ['name', 'email'],
    ['Ivan', 'ivan@example.com']
);
```

Значения передаются в PDO через плейсхолдеры `?`.

### find

Возвращает одну строку по полю `id` в виде ассоциативного массива. Если запись
не найдена, `PDOStatement::fetch()` возвращает `false`.

```php
$user = $users->find(['id', 'name', 'email'], 1);
```

### findAll

Возвращает массив всех строк с выбранными колонками.

```php
$allUsers = $users->findAll(['id', 'name', 'email']);
```

Для выбора всех колонок можно передать `['*']`.

### update

Обновляет переданные колонки строки по `id`.

```php
$users->update(
    ['name', 'email'],
    ['Ivan Petrov', 'ivan.petrov@example.com'],
    1
);
```

Сейчас метод выполняет отдельный SQL-запрос для каждой переданной колонки.

### delete

Удаляет строку по `id`.

```php
$users->delete(1);
```

## Проверка данных и ошибки

Для `create()` и `update()` количество колонок должно совпадать с количеством
значений. Пустые массивы или разное количество элементов не выполняют запрос.

`create()`, `update()` и `delete()` возвращают `true` при успешном запросе и
`false` при ошибке. `find()` возвращает строку или `null`, а `findAll()` —
массив. Ошибки PDO и ошибки проверки колонок записываются в `log/system.log`
и не выводятся в HTTP-ответ. Некорректное имя таблицы в конструкторе вызывает
`InvalidArgumentException`.

## Безопасность

PDO-плейсхолдеры защищают только значения, но не имена таблиц и колонок.
Поэтому `CRUD` проверяет каждое переданное имя колонки и оборачивает его в
обратные кавычки. Не передавайте в массиве колонок SQL-выражения, например
`'name, password'` или `'id; DROP TABLE users'`: они будут отклонены.
