# Документация Mini Framework

Эта папка описывает классы и команды Mini Framework.

## Готовый функционал

- `router.md` - роутинг и запуск контроллеров.
- `response.md` - отправка JSON-ответов.
- `request.md` - получение данных из HTTP-запроса.
- `logger.md` - системное логирование Core-классов.
- `controller.md` - базовый класс будущих контроллеров.
- `middleware.md` - базовый middleware и проверка авторизованного пользователя.
- `connect-db.md` - подключение к базе данных через PDO и `.env`.
- `create-table.md` - создание таблиц и изменение колонок.
- `crud.md` - базовые операции с записями таблицы и правила безопасности.
- `migrations.md` - запуск миграций через `MigrationManager`.
- `commands.md` - консольные команды из `command.php`.
- `auth.md` - регистрация, вход, сессии и защищённые маршруты.

## Идея структуры

`Core` - ядро фреймворка. В нем лежат классы, которые не относятся к конкретной бизнес-логике, а помогают приложению работать: маршруты, запросы, ответы, подключение к базе, CRUD-операции и базовые инструменты для миграций.

## DI container

- `container.md` - DI-контейнер, `app/bootstrap/app.php`, создание Core-классов,
  контроллеров и middleware через `Container::make()`.
